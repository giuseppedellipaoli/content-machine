# Visual assets

## Cover

`content-machine-cover.jpg` is original AI-generated brand artwork, produced with the built-in `imagegen` tool on October 20, 2026. The prompt is recorded in [imagegen-prompt.txt](imagegen-prompt.txt). It is an illustration of the project concept, not a screenshot, benchmark, or generated result from the video engine.

The generated source was preserved on the author's data drive and exported as a same-size JPEG for web delivery. The repository image is below 1 MB and uses a 2:1 aspect ratio, suitable for GitHub's social preview.
