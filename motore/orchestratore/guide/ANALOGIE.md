# Scelta di una forma visiva

La forma aiuta a leggere quello che è già detto: non aggiunge una prova.

Sequenza -> nodi in ordine; confronto -> due colonne; direzione -> freccia; relazione -> network; elenco -> griglia o pillole; numero -> contatore/barre con dati verificati. Una citazione resta una citazione: non trasformarla in statistica.

Quando il significato non ha una forma utile, una card con poche parole fedeli è sufficiente. Evitare animazioni decorative continue che sottraggono attenzione alla persona o alla dimostrazione. Inserti specifici devono venire dai materiali autorizzati del lavoro corrente.
