# Opening a short

Choose an opening that makes the clip's subject clear and is supported by the source recording. Prefer a complete thought over a fragment that needs missing context. Keep quotations faithful to the transcript and check cuts by watching the rendered result.

The first seconds can use fewer words per subtitle page. This is controlled by `sottotitoli_short.parole_per_pagina_primi_10s` in `motore/brand-kit.json`; subsequent pages use `parole_per_pagina`. These are editable presentation choices, with no promised engagement or performance outcome.

The assistant can propose selections and overlay plans. The renderer does not call an LLM or publish content. Review the JSON and output files before using them.
