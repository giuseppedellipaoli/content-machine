# Content Machine per Claude

Leggi `AGENTS.md` e `skills/content-machine/SKILL.md`. Il repository si usa direttamente da Claude Code, Codex o un altro agente con accesso a file e terminale. Non occorre un server web né un token API nel progetto.

Avvio: `python tools/content_machine.py doctor`. Poi segui il brief dell'utilizzatore e il ramo di `docs/WORKFLOW.md`. Usa il venv di questo clone e un nuovo lavoro sotto `work/jobs/`.
